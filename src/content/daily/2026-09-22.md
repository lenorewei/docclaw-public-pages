#### [Cloudflare Python Workers are now generally available](https://simonwillison.net/2026/Sep/21/cloudflare-python-worker/)

_Simon Willison V2_

摘要：Cloudflare Python Workers 现已全面可用。经过两年预览，该平台对运行 Python 代码的支持已稳定，Python 成为 Cloudflare 开发者平台的一等公民。其实现方式为：通过 Pyodide 将 Python 编译为 WebAssembly，在基于 V8 的 workerd 运行时中执行。限制包括 multiprocessing 和 threading 不可用。本地开发工具 pywrangler（在 PyPI 上名为 workers-py）会在约 123MB 的 workerd 二进制中完整模拟该栈，包括用 Pyodide 在 V8 中执行 WebAssembly。Cloudflare 对 Python 生态进行了重大投资，致谢名单包括 Pyodide 核心维护者 Gyeongjae Choi 和 Hood Chatham。
