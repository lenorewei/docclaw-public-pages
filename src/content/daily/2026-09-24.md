### 技巧与观点

#### [团队分享提升 Agent Harness Token 效率的提示词](https://x.com/ericzakariasson/status/2102853511637774551)

_X：Eric Zakariasson (@ericzakariasson) · x.com_

一份公开提示词用于优化 LLM Agent Harness，目标是在不降低任务质量的前提下降低每任务的价格加权 token 成本。某团队一轮改动（提示词精简、工具卸载、缓存布局、稀疏行号、子智能体调优）将整体 token 成本降低约 7%，且质量无损。提示词强调按任务而非按请求计量，并建议先映射 harness、测量基线，再按优先级实施改动。

#### [世界名画｜维米尔：今日美学训练](http://www.wikidata.org/entity/Q2267440)

_维米尔_

怎么看：**今日画家**：维米尔（Johannes Vermeer），今天重点看窗边光线、安静空间和人物视线。

**作品**：《坐在維金納琴旁的年輕女子》

- **画家 / 信息**：画家 Johannes Vermeer，创作时间 1670
- **画家和这幅画**：《坐在維金納琴旁的年輕女子》适合放在维米尔的“室内光线”脉络里看：人物不靠大动作表达情绪，而是靠光线、脸部朝向和安静空间制造停顿感。
- **背景**：这件作品适合用来观察画面如何安排主题、色块、视线动线和视觉重心。
- **怎么看**：先找主角和视觉重心，再看光线、色块和人物/物体关系怎样把故事带出来。
