#### [tester-army/e2e](https://github.com/tester-army/e2e)

_GitHub Trending_

摘要：e2e 是一个面向 Web 与移动应用的端到端测试框架：用自然语言描述目标，由代理驱动应用达成，再用定位器和断言检查结果；代理步骤会被记录并在下次运行中重放，直至应用变化，且无需模型调用。无代理步骤的测试不需要模型。用户可自带订阅或 API key，初始化时选择引擎和模型提供商以生成配置与示例。项目包含 SDK/运行器/CLI、基于 Playwright 的 Web 引擎、iOS/Android 移动引擎、GitHub 报告器、托管浏览器/模拟器、决策模型执行器等包。文档在线及离线可用，CLI 发送匿名使用数据可退出，尚处 1.0 前活跃开发。
