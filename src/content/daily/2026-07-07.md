#### [Claude Code 团队详解四种智能体循环类型](https://x.com/ClaudeDevs/status/2074208949205881033)

_X：Claude Devs (@ClaudeDevs) · x.com_

Claude Code 团队将“设计循环”定义为智能体重复工作直到满足停止条件，划分四种类型：1）回合循环——手动提示触发，Claude 自判完成，适合短任务，可通过 SKILL.md 提升验证；2）目标循环——`/goal` 手动触发，达成目标或达最大轮数停止，需确定性完成标准（如测试通过数）；3）时间循环——`/loop` 和 `/schedule` 按间隔触发，适合同步消息、检查 PR 等重复任务，可云端运行；4）主动循环——事件或计划触发，无人实时参与，每个子任务独立退出。建议从最简单方案开始，选择性使用复杂循环。

### 美学训练

#### [The Met：今日美学训练](https://www.metmuseum.org/art/collection/search/827660)

_The Met_

怎么看：**作品**：《A Bouquet of Flowers》

- **画家 / 信息**：画家 Clara Peeters，创作时间 ca. 1612
- **画家和这幅画**：《A Bouquet of Flowers》可以和画家的静物处理一起看：重点是物体摆放、材质差异和画面重心怎样形成节奏。
- **背景**：静物画通过日常物件组织色彩、材质和空间关系。看这种画不要只认“画了什么”，更要看物体之间怎样形成节奏、遮挡和重心。
- **怎么看**：先找主角和视觉重心，再看光线、色块和人物/物体关系怎样把故事带出来。

- **背景**：这件作品适合用来观察画面如何安排主题、色块、视线动线和视觉重心。
- **怎么看**：先找主角和视觉重心，再看光线、色块和人物/物体关系怎样把故事带出来。
