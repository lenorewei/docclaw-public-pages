#### [Markdown SVG upgrades](https://simonwillison.net/2026/Aug/16/markdown-svg-upgrades/)

_Simon Willison V2_

摘要：我五月开始构建 markdown-svg-renderer 工具，现已加入不少新功能。它已演变为我分享含 SVG 文档的 Markdown 文本的理想工具。工具很简单：在浏览器中打开该工具并粘贴 Markdown 即可渲染，或将 Markdown 保存到 CORS 友好的 URL 或 GitHub Gist 后粘贴 URL，URL 选项会生成可收藏页面。Markdown 中的 SVG 块会转换为渲染后 SVG（可为动画）及多个标签页。PNG 和 JPEG 标签页可在浏览器中将 SVG 渲染为对应图片格式，便于复制或下载；MP4 标签页是今天新增，会检测 SVG 动画，猜测循环视频时长，渲染多帧并加载 30+MB 的 ffmpeg.wasm，用编译为 WebAssembly 的 FFMPEG 在浏览器中合成 MP4，方便在不支持 SVG 动画的平台分享。

#### [世界名画｜葛饰北斋：今日美学训练](https://www.artic.edu/artworks/2914)

_葛饰北斋_

怎么看：**今日画家**：葛饰北斋（Katsushika Hokusai），今天重点看平面构图、浪形线条和留白。

**作品**：《Hara, from the series ""Fifty-three Stations of the Tokaido (Tokaido gojusan tsugi)""》

- **画家 / 信息**：画家 Katsushika Hokusai 葛飾 北斎，流派/时期 Japanese (culture or style)，创作时间 c. 1806，地区 日本
- **画家和这幅画**：《Hara, from the series ""Fifty-three Stations of the Tokaido (Tokaido gojusan tsugi)""》适合放在北斋的版画语言里看：线条、平面色块和留白会先抓住视线，再把自然力量变成很清楚的图形节奏。
- **背景**：日本版画常用清晰轮廓、平面色块和大胆留白，对现代海报、插画和界面构图都有影响。
- **怎么看**：先找主角和视觉重心，再看光线、色块和人物/物体关系怎样把故事带出来。
