#### [Omarchy: Any User Process Can Escalate to Root](https://0xcc.io/posts/omarchy-root-creds/)

_Hacker News_

摘要：Omarchy 默认将用户加入 docker 组，导致用户会话中几乎所有进程均可通过 Docker 守护进程以 root 权限操作，无需密码或提示。Docker 套接字允许 root 守护进程挂载宿主机文件系统并运行任意代码，普通进程可读取 /etc/shadow。该配置为默认开启，即使用户不使用 Docker 也受影响，普通应用被攻破即可造成整机沦陷。问题经私下披露后已修复。

#### [世界名画｜维米尔：今日美学训练](http://www.wikidata.org/entity/Q2267440)

_维米尔_

怎么看：**今日画家**：维米尔（Johannes Vermeer），今天重点看窗边光线、安静空间和人物视线。

**作品**：《坐在維金納琴旁的年輕女子》

- **画家 / 信息**：画家 Johannes Vermeer，创作时间 1670
- **画家和这幅画**：《坐在維金納琴旁的年輕女子》适合放在维米尔的“室内光线”脉络里看：人物不靠大动作表达情绪，而是靠光线、脸部朝向和安静空间制造停顿感。
- **背景**：这件作品适合用来观察画面如何安排主题、色块、视线动线和视觉重心。
- **怎么看**：先找主角和视觉重心，再看光线、色块和人物/物体关系怎样把故事带出来。
